Multibots

Can I use my ChatGPT subscription instead of an API key for an AI agent?

Yes. Multibots signs in to ChatGPT the way OpenAI's Codex does, with a device code, so the bots it runs on your own computers use your ChatGPT plan instead of an OpenAI API key billed per token. Their requests count toward the Codex usage your plan includes, and Multibots itself is free and open source.

Sign in

First turn on device code login in ChatGPT's security settings; in a workspace, its admin allows it in the workspace's permissions. Then, in Multibots' Settings, under ChatGPT, choose Sign in. Multibots shows a code: open auth.openai.com/codex/device, sign in to ChatGPT there and enter it, and Multibots finishes by itself.

The sign-in stays on the computer that made it, sealed by the system keychain, or on Linux without a keyring in a file only you can read, as Codex keeps it. Each of your servers signs in for itself, since a refresh token works only once. Multibots uses it for its bots alone: their model calls, web searches and voice chats.

Which plans work

OpenAI includes Codex in every ChatGPT plan, but lists Free and Go for its desktop app, subject to rollout (OpenAI's Codex pricing, checked 23 November 2026). A paid plan such as Plus, Pro or Business is the one to count on. Bots share its Codex allowance with the rest of your Codex use.

Bots run on GPT-6.1 Terra where your plan offers it, and otherwise on the first model Codex lists for your account. They get ChatGPT's built-in web search when a run starts on ChatGPT.

When your plan runs out

Add models you host, or any provider with an OpenAI-style API that lists its models at /models and answers chat completions, under Your models, and put them after ChatGPT in Order. Each chat model call goes to the first that answers, so a run that loses ChatGPT midway carries on with the next. To set it all up, follow the install guide.
