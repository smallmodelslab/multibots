Multibots

Can I run an AI agent on models I host, such as Ollama, vLLM or LM Studio?

Yes. Multibots runs its bots on any chat model with tool calling served behind an OpenAI-style API that lists its models at /models and answers /chat/completions, such as Ollama, vLLM, SGLang, LM Studio or llama.cpp's server. In Settings, under Your models, Add model takes the server's address, the model and an optional key. Use your models on their own, with no ChatGPT account, or with ChatGPT in the order you choose.

Connect a model

The address is the server's OpenAI-style API, which usually ends in /v1: by default http://localhost:11434/v1 for Ollama, http://localhost:1234/v1 for LM Studio and http://localhost:8000/v1 for vLLM. Multibots reads the server's /models to suggest the models it serves, so the server must answer /models even when you type the model yourself.

Bots work through tools, so pick a model that supports tool calling, and turn tool calling on in its server where it's off by default, as vLLM's is. To look at screenshots, a bot needs a model that takes images.

Each server keeps its own list of models and calls them itself, so add a model on every server that should use it, and localhost is whichever server runs the bot.

Use them with ChatGPT

With ChatGPT signed in too, Settings lists under Order what chat, transcription and speech each try, in turn. Each step of a run goes to the first chat model that answers; a model that can't be set up when a run first needs it, as when ChatGPT can't list its models, sits out the rest of that run. A model further down gets the recent conversation, trimmed further when its context window is smaller: the window its server reported when you added it, or 128K tokens when the server didn't say. ChatGPT's built-in web search comes only with a run that starts on ChatGPT, though a bot on any model can browse in its Chrome tabs. See using your ChatGPT subscription.

Voice chats

Add a transcription model and a speech model too, such as open speech models served by mlx-audio. A voice chat stays on ChatGPT's voice or on your models, whichever it starts on. On yours, Multibots sends what you say between pauses to the first transcription model that answers, and plays the reading of the first speech model that answers. To set it all up, follow the install guide.
